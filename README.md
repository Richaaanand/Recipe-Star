# Recipe Star - React Recipe App

## Overview

Recipe Star is a React-based web application that allows users to search for recipes and view detailed instructions, including a list of ingredients and preparation steps for a selected dish.

---

## Visit Here

https://recipe-star.netlify.app/

---

## Technologies Used

* **React** – Frontend framework for building the user interface
* **React Router** – For handling client-side routing and navigation
* **Forkify API** – External API used to fetch recipe data

---

## Features

* Search for recipes by dish name or ingredient
* View detailed recipe information including ingredients and preparation procedure
* Seamless navigation between search results and recipe details
